# Nation Seed Data

This directory contains JSON seed files for national teams.

## File Format

```json
[
  {
    "apiId": 2,
    "name": "Brazil",
    "code": "BR",
    "flag": "logos/nations/brazil.png",
    "confederation": "CONMEBOL"
  }
]
```
