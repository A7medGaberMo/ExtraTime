# Club Seed Data

This directory contains JSON seed files for football clubs.

## File Format

```json
[
  {
    "apiId": 85,
    "name": "Paris Saint-Germain",
    "shortName": "PSG",
    "logo": "logos/clubs/psg.png",
    "league": "Ligue 1",
    "country": "France"
  }
]
```
